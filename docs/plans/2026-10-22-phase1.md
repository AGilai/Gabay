# Gabbai app, phase 1: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable, offline Hebrew web app (PWA) for Android that runs the weekday Torah-reading
call-ups (S1–S9 of the spec), seeded from the gabbai's WhatsApp log.

**Architecture:** Pure logic lives in `core/*.ts`: types, calendar, slots, the fairness order, the
WhatsApp import, prayers and backup. It has no DOM and is tested with `node --test`. The UI lives in
`web/*.ts`: vanilla DOM, one module per screen. It keeps one `State` object in memory and saves it
as a single JSON record in IndexedDB. A zero-dependency build script strips the TypeScript types
(`node:module` `stripTypeScriptTypes`) into `dist/`, which is served as static files (GitHub Pages).
A hand-written service worker makes it work offline and installable.

**Tech Stack:** Node ≥ 22.18 (TypeScript type stripping), `node --test`, no npm dependencies. The
Hebrew calendar is the `@hebcal/core` 5.10.1 browser bundle, vendored as `vendor/hebcal.min.js`
(GPL-2.0, so the app is licensed GPL-2.0-or-later).

**Spec:** `docs/UX-DESIGN.md` (draft 3). Mockup: `design/mockups/ux-screens.html`.

## Global Constraints

- All UI copy is Hebrew, `dir="rtl"`, `lang="he"`. Copy is taken verbatim from the spec and the mockup.
- Android portrait. It must fit 360×800 dp with no scrolling on S1 with 4 slots plus a banner (spec §10.1).
- Touch targets ≥ 48 dp. Sizes as in spec §10.1. The design tokens (colours, fonts) are copied from the mockup's `:root`.
- **The main page (S1), the slot sheet (S3) and prayer texts never show `hint`.** Only S2 and S5 show it.
- The calling line is shown exactly as stored. The app never adds `הכהן` / `הלוי` / the slot word to it.
- The calendar is Israel (`il = true`). Nusach Sfard. The prayer texts are placeholders, editable in settings.
- Offline: no network call at run time except the service worker's update check.
- TypeScript limited to what type stripping accepts: no `enum`, `namespace`, parameter properties or decorators. Imports use `.ts` extensions.
- Dates are local `YYYY-MM-DD` strings (`ISODate`). Times are `HH:MM`. Never use `Date.toISOString()` for a day (it shifts by the time zone).
- Real congregant data (`*.zip`, `Screenshot*.png`, `private/`) is never committed.
- No `npm install`: the machine has 2 GB RAM, and there is nothing to install.

## Review Focus

1. **A day the calendar gets wrong** (Rosh Chodesh on Shabbat, a fast moved by Shabbat, Ta'anit Bechorot, Chanukah with Rosh Chodesh Tevet): the gabbai expects the switch to save him. Test: Task 2 pins `reading` / `defaultCount` for each of those, and Task 4 tests that `relayout` overrides the count.
2. **The WhatsApp export is messy** (multi-line messages, a forwarded list, "deleted" / "pinned" / ".", edited tags, double spaces, `בר'` / `ב""ר`). The import must not create junk people. Test: Task 5's fixture contains each case, and the local real-file check reports 0 lines skipped unexpectedly.
3. **Undo after a wrong tap** (done on the wrong slot, אין כהן switched on by mistake): the state comes back exactly. Test: Task 4 pins what `relayout` removes, and Task 8's `tests/store.test.ts` pins that `undo()` restores the previous state exactly.
4. **Data loss** (Chrome clears storage, a new phone): the gabbai expects his history back from a backup. Test: Task 7 round-trips `exportBackup` → `parseBackup` on a full state and rejects a truncated file with a Hebrew message.
5. **A person in two places at once** (picked twice, or the same Kohen in Kohen + "Kohen in place of Levi"): only the K_FOR_L case is allowed. Test: Task 4 `place` returns `{error:'already'}` for a second placement, but layout fills K_FOR_L with slot 0's Kohen.

### Task 5: WhatsApp import (parse, draft, apply) + unzip

**Files:** Create `core/unzip.ts`, `core/whatsapp.ts`, `tests/fixtures/chat-sample.txt`, `tests/fixtures/chat-sample.zip` (built from the .txt with python `zipfile`, DEFLATED), `scripts/check-import.ts`. Test: `tests/whatsapp.test.ts`

**Interfaces:**
- Consumes: `State`, `Person`, `Reading`, `Group`, `normalize`, `newId`, `ROLE` types.
- Produces:
```ts
export async function readZipEntry(data: Uint8Array, nameEndsWith: string): Promise<string | null> // core/unzip.ts
export interface RawEntry { date: ISODate; time: string; text: string }
export function parseChat(text: string): { entries: RawEntry[]; skipped: string[] }
export function personKey(line: string): string      // normalize, remove (..), בר'/ב"ר→בן, drop trailing הכהן/הלוי
export function groupFromLine(line: string): Group
export interface DraftPerson { key: string; name: string; callLine: string; group: Group;
  groupCounts: Record<Group, number>; hints: string[]; dates: { date: ISODate; time: string }[]; regular: boolean }
export type Question =
  | { kind: 'same'; a: string; b: string }                     // keys
  | { kind: 'group'; key: string; counts: Record<Group, number> }
  | { kind: 'hint'; key: string; hint: string }
export interface Draft { people: DraftPerson[]; questions: Question[] }
export function buildDraft(entries: RawEntry[], today: ISODate): Draft
export type Answer = 'merge' | 'separate' | Group | 'keep' | 'drop'
export function applyDraft(state: State, draft: Draft, answers: Answer[]): State  // answers[i] ↔ questions[i]
```
Parsing: the line regex is `^‎?\[(\d\d)/(\d\d)/(\d{4}), (\d{1,2}):(\d\d)(?::\d\d)?\] [^:]+: (.*)$`. A line without a
timestamp is its own entry with the previous date and time. Strip `‎` and `<This message was edited>`.
Strip a forwarded prefix `^\[\d+/\d+, [\d:]+\] [^:]+: `. Skip (into `skipped`) entries that are empty, `.`,
contain `deleted`, `pinned`, `omitted`, or end with `:` / `שניתנו`. Draft: the callLine is the latest
spelling with the parentheses removed. The name is `personKey` (spec S8). The group is the majority; a
`group` question is raised when another group appears more than once, or for a 1-vs-many conflict where the
minority is `K` / `L`. A `same` question is raised for key pairs with similarity ≥ 0.88 (1 − Levenshtein /
maxLen). A `hint` question is raised for a hint matching `/(^|\s)(בן|בת)\s/`. `regular` = ≥ 3 dates in the
90 days before `today`. Apply: create the people (`addedOn` = first date). Readings are grouped by
(date, service = time ≥ 12:00 ? mincha : shacharit). Slot roles come from the group in message order
(K→K, L→L, Y→Y3 then Y4, extra → Y4). `doneAt` = time, `source:'whatsapp'`, `count` = slots.length.
